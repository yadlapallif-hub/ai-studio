# Security, Privacy & Ethical Integrity Policy

## 1. Secret & Credential Isolation
- `SUPABASE_SERVICE_ROLE_KEY` and all AI provider secrets (`OPENAI_API_KEY`, `GEMINI_API_KEY`, `GROQ_API_KEY`, `OPENROUTER_API_KEY`, `OLLAMA_API_KEY`, `REMOVE_BG_API_KEY`) are read exclusively inside Next.js Route Handlers and Supabase Edge Functions.
- The Admin `/ai` portal displays boolean environment readiness (`Env Key Set` / `Not Set`) and never returns raw secret values to any browser client.

## 2. Role-Based Authorization (`admin-website`)
- Middleware verifies authenticated sessions before serving admin routes.
- Every server page and `/api/admin/*` route checks `getAdminContext(requiredRoles)` against `fcs_user_roles` via service-role lookup.
- Only `super_admin` can modify `fcs_user_roles`, update `ai_config` / `security` settings, or delete user accounts.
- Optional TOTP Multi-Factor Authentication is available under `/security`.

## 3. Credential Verification & Stamp Integrity
- Decorative sample stamps generated by `createDecorativeSampleStampSvg` explicitly include visible `"SAMPLE"` / `"PREVIEW ONLY"` / `"DECORATIVE"` wording and `isSampleDecorative: true`.
- Uploading custom organizational stamps, seals, or signatures requires user attestation confirming organizational authorization.
- Database triggers (`fcs_guard_verification_insert` & `fcs_guard_verification_update`) reject any attempt by non-staff users to set `verification_status = 'verified'`, and Admin approval requires linking to an `approved` organization in `fcs_authorized_issuers`.

## 4. AI Honesty & User Control
- AI edits in Resume Studio always appear as **preview diffs** requiring explicit user acceptance (`Apply Approved AI Draft` / `Discard`).
- ATS scores include an explicit disclaimer noting that no ATS score guarantees hiring outcomes.
- Career roadmaps never fabricate live job vacancies or salary guarantees.
- Users may disable AI personalization or clear conversation history at any time (`/assistant`, `/settings`).
